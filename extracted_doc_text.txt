I. Overview
The Job Management System is a web-based application designed to manage job postings, applications, and user accounts efficiently. The system provides different access levels for users, employers, administrators, and guests to ensure secure and organized workflow. It allows users to search and apply for jobs, employers to post and manage job advertisements, and administrators to oversee the entire system.
The project is developed using Java Servlet, JSP, and JDBC technologies, with data managed by the Microsoft SQL Server database system. This system was created to streamline the recruitment process, enhance data management, and improve communication between job seekers and employers.

3.1 Database Schema
3.2 Table Descriptions
No
Table
Description
1
Jobs
Stores detailed information about posted job listings (Title, Description, Salary, Location, Requirements...).
2
Categories
Manages job categories (e.g., "IT", "Marketing", "Accounting").
3
Companies
Stores information about the companies posting jobs (Name, Description, Location, Website...).
4
Users
Manages user accounts (Email, Password, FullName, Phone...). This is a central table for both students and employers.
5
Roles
Defines the roles within the system (e.g., "Admin", "Student", "Employer").
6
Applications
Manages student applications for jobs, including status and the CV snapshot (CVSnapshot).
7
Students
Stores detailed academic information for students (Major, GPA...). This table links to the Users table.
8
Skills
A master list of all available skills (e.g., "React", "SQL", "Communication").
9
JobSkills
A junction table linking a job (JobId) to the multiple skills (SkillId) it requires.
10
StudentSkills
A junction table linking a student (StudentId) to the multiple skills (SkillId) they possess.
